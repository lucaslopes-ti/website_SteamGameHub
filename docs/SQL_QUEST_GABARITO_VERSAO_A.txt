id: select-06
título: SQL vs. NoSQL
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo.
  Pergunta 1: Cada banco NoSQL tende a usar ____ linguagem(ns) de consulta.
    A) a mesma
    B) diferentes
    Correta: B) diferentes
    Explicação: Cada sistema NoSQL costuma ter sua própria forma de escrever e executar consultas.
  Pergunta 2: Bancos compatíveis com ____ tendem a ser mais parecidos em funcionalidade do que bancos ____.
    A) SQL, NoSQL
    B) NoSQL, SQL
    Correta: A) SQL, NoSQL
    Explicação: Bancos relacionais são bastante parecidos entre si; bancos NoSQL tendem a ser únicos e voltados a propósitos específicos.

Capítulo 3 — Lição 8
id: restricoes-08
título: Revisão de constraints
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo.
  Pergunta 1: Qual constraint identifica cada linha de forma única e não aceita NULL?
    A) PRIMARY KEY
    B) NOT NULL
    C) DEFAULT
    D) UNIQUE
    Correta: A) PRIMARY KEY
    Explicação: A PRIMARY KEY identifica cada linha de forma única; não aceita duplicatas nem NULL.
  Pergunta 2: Qual constraint garante que uma coluna sempre tenha um valor em todo INSERT?
    A) NOT NULL
    B) UNIQUE
    C) DEFAULT
    D) FOREIGN KEY
    Correta: A) NOT NULL
    Explicação: NOT NULL impede que a coluna receba valores NULL.
  Pergunta 3: Qual constraint impede que duas linhas tenham o mesmo valor em uma coluna?
    A) PRIMARY KEY
    B) NOT NULL
    C) UNIQUE
    D) DEFAULT
    Correta: C) UNIQUE
    Explicação: UNIQUE garante que não existam valores duplicados na coluna.
  Pergunta 4: Qual constraint exige que o valor da coluna exista em outra tabela?
    A) PRIMARY KEY
    B) FOREIGN KEY
    C) UNIQUE
    D) NOT NULL
    Correta: B) FOREIGN KEY
    Explicação: FOREIGN KEY referencia uma PRIMARY KEY (ou coluna UNIQUE) de outra tabela.
  Pergunta 5: Qual constraint usa um valor automático quando nenhum é fornecido no INSERT?
    A) DEFAULT
    B) NOT NULL
    C) UNIQUE
    D) FOREIGN KEY
    Correta: A) DEFAULT
    Explicação: DEFAULT define um valor usado automaticamente quando o campo é omitido.

    A) Valores que começam com 'or' e têm exatamente 3 caracteres.
    B) Valores que começam com 'or' e têm pelo menos 3 caracteres.
    C) Valores que terminam com 'or' e têm pelo menos 3 caracteres.
    D) Valores que terminam com 'or' e têm exatamente 3 caracteres.
    Correta: B) Valores que começam com 'or' e têm pelo menos 3 caracteres.
    Explicação: O padrão 'or_%' exige 'or' seguido de pelo menos um caractere (_) e depois qualquer quantidade (%). Ou seja, os valores começam com 'or' e têm no mínimo 3 caracteres.
  Pergunta 2: Qual das opções NÃO corresponderia ao exemplo 2 (`name LIKE '__ing'`)?
    A) thing
    B) sling
    C) singing
    D) bling
    Correta: C) singing
    Explicação: '__ing' corresponde a palavras com exatamente 5 caracteres que terminam em 'ing'. 'singing' tem 7 caracteres e não corresponde ao padrão.

id: normalizacao-04
título: Normalização de banco de dados
natureza: quiz
critério canônico (quiz):

  Pergunta 1: Para melhorar a integridade dos dados, os dados devem, em geral, ser armazenados de qual forma?
    A) Bruta (raw)
    B) Pré-calculada (precomputed)
    Correta: A) Bruta (raw)
    Explicação: Dados brutos nunca mudam. Um dado derivado, como a idade, fica desatualizado com o tempo.
  Pergunta 2: Qual é o melhor exemplo de redundância de dados?
    A) Duas tabelas que têm um campo booleano
    B) Cada tabela ter um campo id como chave primária
    C) O endereço de um usuário estar armazenado em duas tabelas diferentes
    D) Uma tabela countries e uma tabela users terem, cada uma, um campo name
    Correta: C) O endereço de um usuário estar armazenado em duas tabelas diferentes
    Explicação: Redundância é a mesma informação guardada em vários lugares — como o mesmo endereço em duas tabelas.
  Pergunta 3: Por que armazenar a idade em vez da data de nascimento prejudica a integridade?
    A) Porque ocupa mais espaço em disco
    B) Porque a idade fica desatualizada com o passar do tempo
    C) Porque o tipo INTEGER é mais lento
    D) Porque impede a criação de índices
    Correta: B) Porque a idade fica desatualizada com o passar do tempo
    Explicação: A idade é um dado pré-calculado: cada aniversário a torna incorreta. A data de nascimento é bruta e nunca muda.
  Pergunta 4: Qual é o objetivo da normalização?
    A) Aumentar a redundância para acelerar consultas
    B) Melhorar a integridade dos dados e reduzir a redundância
    C) Garantir que toda tabela tenha uma chave estrangeira
    D) Eliminar a necessidade de chaves primárias
    Correta: B) Melhorar a integridade dos dados e reduzir a redundância
    Explicação: Normalizar é estruturar o schema para melhorar a integridade e reduzir a duplicação.

Capítulo 9 — Lição 9
id: normalizacao-09
título: Forma normal de Boyce-Codd (BCNF)
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo sobre a BCNF.
  Pergunta 1: Quando uma tabela pode estar na 3NF, mas não na BCNF?
    A) Quando Boyce e Codd decretam que sim
    B) Quando ela tem múltiplas chaves primárias possíveis
    C) Quando tem múltiplas chaves candidatas sobrepostas e uma coluna de uma chave depende de uma coluna fora dela
    D) Quando a chave primária depende de uma coluna que não é chave
    Correta: C) Quando tem múltiplas chaves candidatas sobrepostas e uma coluna de uma chave depende de uma coluna fora dela
    Explicação: A BCNF restringe como colunas que fazem parte da chave primária podem depender de colunas que não fazem parte dela.
  Pergunta 2: O que significa 'chaves candidatas sobrepostas'?
    A) Várias combinações de colunas que poderiam ser a chave primária e que compartilham colunas
    B) Duas tabelas diferentes com o mesmo nome
    C) Uma chave primária com dois tipos de dados diferentes
    D) Chaves estrangeiras que apontam para a mesma tabela
    Correta: A) Várias combinações de colunas que poderiam ser a chave primária e que compartilham colunas
    Explicação: Chaves candidatas são combinações que identificam uma linha; 'sobrepostas' quer dizer que elas compartilham colunas.
  Pergunta 3: Com que frequência uma tabela na 3NF deixa de atender à BCNF?
    A) Sempre
    B) Na maioria dos casos
    C) Apenas em casos raros
    D) Nunca
    Correta: C) Apenas em casos raros
    Explicação: É raro encontrar problemas específicos de BCNF na prática.

Capítulo 11 — Lição 2
id: performance-02
título: Como os índices funcionam
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo sobre índices e desempenho.
  Pergunta 1: Um índice B-tree faz com que as buscas sejam...
    A) O(n^2)
    B) O(n*log(n))
    C) O(n)
    D) O(log(n))
    Correta: D) O(log(n))
    Explicação: A B-tree mantém os valores ordenados e divide a busca a cada nível, resultando em complexidade O(log(n)).
  Pergunta 2: Por que não devemos indexar todas as colunas de uma tabela?
    A) Porque o SQLite só permite um índice por tabela
    B) Porque cada índice ocupa memória e deixa INSERT/UPDATE mais lentos
    C) Porque índices impedem o uso de JOINs
    D) Porque índices só funcionam em chaves estrangeiras
    Correta: B) Porque cada índice ocupa memória e deixa INSERT/UPDATE mais lentos
    Explicação: Vários índices incham o uso de memória e obrigam cada escrita a atualizar várias árvores.
  Pergunta 3: Quais colunas já vêm indexadas automaticamente?
    A) Apenas colunas do tipo TEXT
    B) As colunas que aceitam valores NULL
    C) As colunas PRIMARY KEY
    D) Nenhuma coluna
    Correta: C) As colunas PRIMARY KEY
    Explicação: As colunas PRIMARY KEY são indexadas por padrão, o que torna a busca por id muito rápida.
  Pergunta 4: Qual é a regra prática sobre índices?
    A) Indexar todas as colunas para garantir velocidade
    B) Indexar as colunas usadas com frequência em buscas e deixar o resto sem índice
    C) Nunca criar índices em produção
    D) Criar índices apenas em colunas booleanas
    Correta: B) Indexar as colunas usadas com frequência em buscas e deixar o resto sem índice
    Explicação: Adicione índices às colunas em que você fará buscas frequentes; você sempre pode adicionar outro depois.

Capítulo 11 — Lição 4
id: performance-04
título: Desnormalização por velocidade
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo sobre desnormalização.
  Pergunta 1: A desnormalização pode ser usada para ____
    A) Reduzir dados duplicados
    B) Acelerar as consultas
    Correta: B) Acelerar as consultas
    Explicação: Guardar dados duplicados evita operações custosas, como JOINs, e por isso pode acelerar as consultas.
  Pergunta 2: É inteligente começar com um banco ____ e ____ conforme a necessidade por velocidade.
    A) Normalizado, desnormalizar
    B) Desnormalizado, normalizar
    Correta: A) Normalizado, desnormalizar
    Explicação: Comece normalizado para garantir integridade; desnormalize pontualmente se surgirem problemas de desempenho.
  Pergunta 3: Qual banco é mais fácil de manter livre de bugs?
    A) Normalizado
    B) É indiferente
    C) Desnormalizado
    Correta: A) Normalizado
    Explicação: Com dados sem duplicação, há menos chance de cópias ficarem inconsistentes entre si.
  Pergunta 4: Qual é o principal risco ao desnormalizar um banco?
    A) Passar a exigir mais JOINs
    B) Dados imprecisos e inconsistentes
    C) Impedir o uso de chaves primárias
    D) Perder a capacidade de criar índices
    Correta: B) Dados imprecisos e inconsistentes
    Explicação: Dados duplicados podem divergir; por isso desnormalizar é arriscado e deve ser o último recurso.

Capítulo 11 — Lição 5
id: performance-05
título: SQL injection
natureza: quiz
critério canônico (quiz):
  instrução: Responda às perguntas abaixo sobre SQL injection.
  Pergunta 1: SQL injection é melhor evitado usando uma biblioteca moderna de SQL que cuida da sanitização dos valores fornecidos pelo usuário.
    A) Verdadeiro
    B) Falso
    Correta: A) Verdadeiro
    Explicação: Bibliotecas modernas sanitizam entradas automaticamente; não precisamos mais higienizar tudo na mão.
  Pergunta 2: O que o exemplo `Robert'); DROP TABLE students;--` demonstra?
    A) Que o SQLite apaga tabelas automaticamente
    B) Que inserir entrada do usuário direto na query permite executar comandos extras
    C) Que chaves primárias evitam ataques
    D) Que nomes com apóstrofo são inválidos em SQL
    Correta: B) Que inserir entrada do usuário direto na query permite executar comandos extras
    Explicação: Sem sanitização, a entrada fecha a query original e injeta uma segunda instrução que apaga a tabela.
  Pergunta 3: Qual é a prática recomendada ao usar entrada do usuário em consultas?
    A) Concatenar os valores diretamente na string SQL
    B) Remover manualmente todos os apóstrofos
    C) Passar os valores como parâmetros para a biblioteca de banco
    D) Guardar a query em uma coluna TEXT
    Correta: C) Passar os valores como parâmetros para a biblioteca de banco
    Explicação: Passe valores como parâmetros: a biblioteca trata a entrada como dado, e não como parte do comando SQL.
  Pergunta 4: No ataque de exemplo, para que serve o `--` no final da entrada?
    A) Comentar o restante da query, ignorando o que vem depois
    B) Encerrar a conexão com o banco
    C) Criar um índice temporário
    D) Indicar que a string é um parâmetro
    Correta: A) Comentar o restante da query, ignorando o que vem depois
    Explicação: Em SQL, `--` inicia um comentário e descarta o resto da instrução original.
