## Contexto

Structured Query Language, ou SQL, é a principal linguagem usada para gerenciar
e interagir com bancos de dados relacionais. SQL pode criar, atualizar, ler e
deletar registros dentro de um banco.

Enquanto planilhas são ótimas para manipulação manual simples, SQL é projetado
para operações de dados automatizadas e escaláveis — lida com grandes
conjuntos de dados e integra-se facilmente com linguagens como Python,
TypeScript e Go.
