# SENAI Dr. Celso Charuri Game HUB

Repositório de jogos desenvolvidos pelos alunos do curso Técnico em Programação de Jogos Digitais do SENAI Dr. Celso Charuri.

## 🚀 Tecnologias

- **Next.js 14** - Framework React
- **TypeScript** - Tipagem estática
- **TailwindCSS** - Estilização
- **Firebase** - Backend (Storage, Firestore, Auth)
- **Lucide React** - Ícones

## 📦 Instalação

```bash
npm install
```

## ⚙️ Configuração

1. Copie `.env.example` para `.env.local`
2. Preencha com suas credenciais Firebase
3. Configure as regras de segurança no Firebase Console

## 🛠️ Comandos

```bash
# Desenvolvimento
npm run dev

# Build de produção
npm run build

# Iniciar produção
npm start

# Testar conexão Firebase
npm run test:firebase

# Migrar dados para Firebase
npm run migrate:firebase
```
